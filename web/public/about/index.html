About the project

Files Format

A straightforward collection of free tools for PDFs, images, text and everyday files.

What Files Format does

Files Format brings common file utilities into one browser-based website. Choose a task, select a file or enter text, run the tool and download or copy the result.

Local processing

PDF, image and text processing takes place in your browser. Selected documents are not uploaded to a Files Format processing server. The website itself is hosted by GitHub Pages, which may receive standard website request metadata.

Included tools

  • PDF merge, split, extract pages, rotate, images to PDF and PDF to PNG.
  • Image resize, conversion and compression.
  • Text formatting, JSON and CSV conversion, URL and Base64 encoding, percentage calculations and unit conversion.

Known limits

Encrypted PDFs, OCR, editing text in existing PDFs, signatures, form filling, annotation editing and animated image processing are not supported. Each tool page explains its input and limits.
