AI integration

Connect Files Format to AI tools

Files Format includes a remote MCP server for AI clients that support the Model Context Protocol (MCP). This is a modern MCP integration, not the old-style plugin store.

What the connector exposes

  • Search and list all 27 Files Format utilities.
  • Read tool descriptions and return direct links that open the matching utility in the website.
  • Run 18 text and data operations, including JSON, CSV, case conversion, URL/Base64, percentage calculations and unit conversion.

PDF and image operations remain in your browser. The MCP service does not accept PDF or image uploads.

Free MCP address

The connector is designed for Cloudflare Workers Free and uses the account's included workers.dev subdomain. No purchased domain is needed for the MCP endpoint. Cloudflare assigns your account subdomain; the final address will look like this:

https://files-format-mcp.YOUR-SUBDOMAIN.workers.dev/mcp

This is a separate free subdomain. It cannot be placed under this GitHub Pages hostname without moving the website behind a host that can route both the website and the Worker.

Deploy the MCP server

The source is stored in this repository under mcp-server/. A Cloudflare account is needed to create the free workers.dev address and deploy the Worker.

  1. Open Cloudflare Dashboard and create or sign in to an account.
  2. Open Workers & Pages and connect this GitHub repository, or deploy through Wrangler from a terminal.
  3. For Git integration, set the project root directory to mcp-server. Keep the Worker name as files-format-mcp.
  4. Use npm install and npm run deploy as the install and deploy commands, or follow the CLI steps in the repository's mcp-server/README.md.
  5. After deployment, Cloudflare will show the final workers.dev hostname. Add /mcp to it for the MCP URL.

Test it

Open the deployed Worker's /health address. It should return a JSON response showing status: ok, five MCP actions and 27 catalogue tools. The connection URL to enter in an MCP client is the same hostname followed by /mcp.

Connect an AI client

In an MCP-compatible client, add a remote Streamable HTTP server using the public HTTPS /mcp address. The endpoint does not exist until the Worker is deployed in a Cloudflare account.

ChatGPT compatibility

OpenAI currently documents custom MCP connections for ChatGPT Business and Enterprise/Edu workspaces. Pro users can connect custom MCP servers with read/fetch permissions only. The current OpenAI requirements do not include the Free plan, so this connector cannot currently be added to a Free ChatGPT account. Other compatible AI clients may connect to the same endpoint.

Privacy and limits

Tool discovery requests contain only search terms and tool slugs. When an AI client calls a text transformation, the text supplied by that client is sent to Cloudflare for processing. The Worker does not store the input in a database or file store, but Cloudflare processes the network request under its service terms. Do not send confidential information unless you are comfortable with that transfer.

Text input is limited to 32,000 characters per field. The connector does not expose file upload, account access, storage, delete or other write actions.
