Integrations

Connect Files Format to compatible AI tools

Files Format includes a remote Model Context Protocol (MCP) service for compatible AI clients. It lets an AI client discover utilities, retrieve their instructions and run supported text transformations.

Available connector actions

  • Search and list the Files Format utilities.
  • Read descriptions, input requirements and direct links for individual tools.
  • Run supported text and data transformations on text explicitly provided by the client.
  • Prepare a link to open the QR Tool with content prefilled.

Connection address

The MCP service is deployed separately from the website. Use the public HTTPS endpoint ending in /mcp supplied by its hosting provider. The endpoint is available only after the connector service has been deployed.

Connect a client

In an MCP-compatible application, add a remote Streamable HTTP server and enter the connector's full HTTPS /mcp address. The exact connection steps depend on the client. Consult that application's documentation for support and permission requirements.

MCP hosting and connection guide

Privacy and file processing

PDF and image editing remain in the browser. The connector does not receive PDF or image files. Text explicitly sent to a remote transformation action is processed by the connector service; do not submit confidential content unless you accept that transfer.

Link Tool and QR Tool are separate optional sharing features. They upload only the file or text the visitor chooses, after a security check. The resulting URL is public to anyone who has it and expires after seven days. Do not upload confidential or personal material.
