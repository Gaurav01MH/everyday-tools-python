AI integration

Connect Files Format to AI tools

Files Format provides a remote Model Context Protocol (MCP) connector for compatible AI clients. Tool discovery and QR Tool hand-off are available through MCP; file uploads still use the website's Turnstile-protected flow.

What the connector exposes

  • Search and list the 29 Files Format utilities.
  • Read descriptions and direct links for individual tools.
  • Run supported text/data transformations on text explicitly sent by an AI client.
  • Prepare a QR Tool link with short text prefilled so the visitor can complete the share upload.

Free website address

The requested free Cloudflare Pages project name is too-broke-for-a-custom-domain. Once you claim that project name and deploy it, the website address will be:

https://too-broke-for-a-custom-domain.pages.dev/

This is a free platform-provided hostname, not a purchased custom domain. Cloudflare confirms availability when you create the Pages project. The address is not live until that account step and first deployment are complete.

Optional MCP endpoint

The MCP connector is a separate Cloudflare Worker. Its configured free project name is too-broke-for-a-custom-domain-mcp; after deployment its endpoint will look like:

https://too-broke-for-a-custom-domain-mcp.YOUR-ACCOUNT.workers.dev/mcp

Cloudflare assigns the account-specific part of that hostname. The website remains on the Pages address above; these are two different deployments.

Connect an AI client

In an MCP-compatible client, add a remote Streamable HTTP server using the deployed Worker URL ending in /mcp. ChatGPT documents custom MCP connections for eligible Business and Enterprise/Edu workspaces; Pro access is limited to read/fetch permissions. Custom MCP connections are not listed for ChatGPT Free. Other compatible AI clients may use the same endpoint.

File sharing and privacy

Link Tool and QR Tool accept either pasted text or one file up to 10 MB. They upload only the content the visitor explicitly chooses after a Turnstile security check. The resulting URL is public to anyone who has it and expires after seven days. R2 lifecycle cleanup removes expired objects. Do not upload confidential or personal material.

PDF and image editing tools remain browser-local. The MCP service does not accept file uploads and cannot bypass the website's security check.
