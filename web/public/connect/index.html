AI integration

Connect Files Format to AI tools

Files Format includes a remote MCP server for AI clients that support the Model Context Protocol (MCP). This is a modern MCP integration, not the old-style plugin store.

What the connector exposes

  • Search and list all 29 Files Format utilities.
  • Read tool descriptions and return direct links that open the matching utility in the website.
  • Run text/data operations, including JSON, CSV, case conversion, URL/Base64, percentage calculations, unit conversion and safe HTTP/HTTPS link markup; prepare prefilled QR-generator links.

PDF, image and QR image generation remain in your browser. The MCP service does not accept PDF or image uploads.

One free website and MCP address

The combined site is designed for Cloudflare Workers Free. The website and MCP API share one included workers.dev hostname. After deployment, the addresses look like:

https://files-format-files-format-too-broke-for-a-custom-domain.YOUR-SUBDOMAIN.workers.dev/ — website

https://files-format-files-format-too-broke-for-a-custom-domain.YOUR-SUBDOMAIN.workers.dev/mcp — MCP endpoint

No paid custom domain is needed. Cloudflare assigns the account subdomain when you deploy.

Deploy the combined website and MCP server

The Worker source is in this repository's mcp-server/ folder. A Cloudflare account is required to create the free hostname and deploy it.

  1. Open Cloudflare Dashboard and create or sign in to an account.
  2. Open Workers & Pages → Create application → GitHub and connect this repository.
  3. Set the repository root directory to the repository root, not mcp-server.
  4. Set the build command to npm --prefix web install --no-audit --no-fund && PUBLIC_BASE_PATH=/ npm --prefix web run build && npm --prefix mcp-server install --no-audit --no-fund.
  5. Set the deploy command to cd mcp-server && npx wrangler deploy. Keep the Worker name files-format-too-broke-for-a-custom-domain.
  6. Deploy and copy the assigned workers.dev hostname. In the Cloudflare build environment variables, set PUBLIC_SITE_ORIGIN to that exact origin and PUBLIC_BASE_PATH to /, then redeploy. This sets canonical URLs and the sitemap to the new hostname.

Check the MCP endpoint

Open https://files-format-files-format-too-broke-for-a-custom-domain.YOUR-SUBDOMAIN.workers.dev/health. It should return status: ok, six MCP actions and 29 catalogue tools. Connect an MCP-compatible AI client to the same hostname followed by /mcp.

Test it

Open the deployed Worker's /health address. It should return a JSON response showing status: ok, six MCP actions and 29 catalogue tools. The connection URL to enter in an MCP client is the same hostname followed by /mcp.

Connect an AI client

In an MCP-compatible client, add a remote Streamable HTTP server using the public HTTPS /mcp address. The endpoint does not exist until the Worker is deployed in a Cloudflare account.

ChatGPT compatibility

OpenAI currently documents custom MCP connections for ChatGPT Business and Enterprise/Edu workspaces. Pro users can connect custom MCP servers with read/fetch permissions only. The current OpenAI requirements do not include the Free plan, so this connector cannot currently be added to a Free ChatGPT account. Other compatible AI clients may connect to the same endpoint.

Privacy and limits

Tool discovery requests contain only search terms and tool slugs. When an AI client calls a text transformation, the text supplied by that client is sent to Cloudflare for processing. The Worker does not store the input in a database or file store, but Cloudflare processes the network request under its service terms. Do not send confidential information unless you are comfortable with that transfer.

Text input is limited to 32,000 characters per field. The connector does not expose file upload, account access, storage, delete or other write actions.
