Privacy Policy

Last updated: 23 November 2026.

Files selected for processing

PDF, image and text processing takes place in your browser. Files Format does not upload selected files or pasted text to a Files Format processing server. The browser receives the output as a download. The application does not create an account or maintain a file history.

Website hosting

The static website is hosted by GitHub Pages. GitHub may receive standard website request metadata, such as IP address, browser and request information, to deliver and secure the site. This is separate from the content of the files you select for local processing. See GitHub's Privacy Statement for its handling of hosting and account data.

Offline storage

After a successful visit, a service worker can cache static application files for offline use. The Files Format service worker does not intentionally cache selected source files or generated downloads.

Analytics, advertising and accounts

The application does not include analytics scripts, advertising integrations, account sign-in or an AI API.

Your choices

You can clear the site's cached files in your browser's site settings. That removes the offline app copy; it does not delete original documents stored elsewhere on your device.

Changes

This policy may change if the site's hosting or processing behavior changes. The date above will be updated when material changes are made.
