Policies

Privacy Policy

Last updated: 23 November 2026.

Local processing

PDF, image and ordinary text/data processing takes place in your browser. Files selected for these local tools are not uploaded to a Files Format processing server.

Sharing tools

Link Tool and QR Tool are designed as optional upload-based sharing features. They are currently disabled on the GitHub Pages deployment. On this version, they do not upload files or text and no share link can be created.

Website hosting

The public website is delivered through GitHub Pages. GitHub may receive standard website request information needed to serve and secure the site. See GitHub's Privacy Statement for details.

Offline storage

After a successful visit, a service worker can cache static application files for offline use. The service worker deliberately does not cache upload API requests or public share downloads.

Analytics, advertising and accounts

The application does not include analytics scripts, advertising integrations, account sign-in or an AI API.

Your choices

You can clear the site's cached files in your browser's site settings. That removes the offline app copy; it does not delete original documents stored elsewhere on your device.

Changes

This policy may change if the site's hosting or processing behavior changes. The date above will be updated when material changes are made.
