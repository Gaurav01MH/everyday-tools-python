Using DocuMosaic

DocuMosaic provides browser-based tools for ordinary PDF, image, text and data tasks. Use the service only for files and content you have the right to access and process. You are responsible for checking the result before relying on or sharing it.

Keep original copies

Processing may change document structure, orientation, metadata or image quality. Keep an original copy of important documents. Do not rely on DocuMosaic as the only copy of an important file.

Limits and compatibility

Supported formats and safety limits are shown in the app and on each tool page. Encrypted PDFs, OCR, editing existing PDF text, digital signatures, form filling, annotation editing and animated image processing are not supported.
