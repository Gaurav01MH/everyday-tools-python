Using Files Format

Files Format provides browser-based tools for ordinary PDF, image, text and data tasks. Use the service only for files and content you have the right to access. You are responsible for checking results before relying on them.

Link Tool and QR Tool

These features are currently disabled on the GitHub Pages deployment. They do not accept or upload files or text on this version. If sharing is enabled in a future deployment, its public-link and expiry conditions will be disclosed before an upload is made.

Keep original copies

Processing may change document structure, orientation, metadata or image quality. Keep an original copy of important documents. Do not rely on Files Format as the only copy of an important file.

Limits and compatibility

Supported formats and safety limits are shown in the app and on each tool page. Encrypted PDFs, OCR, editing existing PDF text, digital signatures, form filling, annotation editing and animated image processing are not supported.

No guarantee

The tools are provided as-is. Not every file, browser or device will necessarily be supported. Browser memory and device performance can affect processing. Verify all output before using it for important purposes.
